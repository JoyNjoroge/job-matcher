# Extension Icons

Create three PNG icon files in this directory:

## Required Icons:

1. **icon16.png** - 16x16 pixels
   - Used in browser toolbar
   
2. **icon48.png** - 48x48 pixels
   - Used in extension management page
   
3. **icon128.png** - 128x128 pixels
   - Used in Chrome Web Store / Firefox Add-ons listing

## Design Tips:

- Use your CandorApply logo or brand colors
- Keep it simple and recognizable at small sizes
- Use a transparent background (PNG)
- Purple/blue gradient (#667eea to #764ba2) matches the extension UI

## Quick Generation:

You can create icons using:
- Canva (https://canva.com)
- Figma (https://figma.com)
- Online icon generators
- Your existing logo (resize to required dimensions)

## Placeholder Icons:

For testing, you can use simple colored squares until you create proper icons.
